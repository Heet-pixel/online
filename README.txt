SHOPEASE - JAVASCRIPT VERSION

Technologies: HTML, CSS and JavaScript only.

How to run:
1. Extract the folder.
2. Open index.html in Chrome/Edge, OR use VS Code Live Server.
3. Browse products, add to cart, register, login, checkout and view your orders.

Checkout flow:
Cart -> Checkout (login required) -> shipping details + payment method (demo) -> Order confirmation -> My Orders.
Free shipping on orders of Rs. 999 and above, otherwise Rs. 49.

Data storage:
Cart, demo accounts and orders are stored in browser localStorage. This version does not use PHP/MySQL.

Product photos are loaded from Unsplash URLs, so internet access is required for the photos.
